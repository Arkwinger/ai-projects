# Overview

Gandalf is an AI security challenge from Lakera where players attempt to bypass AI defenses and retrieve a protected password.

As the challenge progresses, new security controls are introduced, demonstrating concepts such as prompt injection, information disclosure, output filtering, and AI guardrails.

**Website:** https://gandalf.lakera.ai
