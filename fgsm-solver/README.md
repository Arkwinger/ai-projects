# FGSM Adversarial Solver 

This project contains a white-box FGSM adversarial attack solver
used for the Hack The Box Academy AI Evasion module.

## What it does
- Recreates the target MNIST CNN locally
- Crafts an L∞-bounded FGSM adversarial example
- Accounts for PNG quantization
- Submits the adversarial image to the challenge server
