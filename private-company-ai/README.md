# SynAccel Assistant (Legacy Repository)

This repository contains an earlier version of the SynAccel Assistant project.

Development has since moved to a newer implementation that includes:

* Retrieval-Augmented Generation (RAG)
* ChromaDB vector storage
* Semantic search using Sentence Transformers
* Dynamic document management
* Improved document retrieval pipeline
* Enhanced local AI architecture

## Current Project

Active development now takes place in the SynAccel AI repository:

**SynAccel AI**

A local-first AI knowledge assistant combining semantic retrieval, vector search, and self-hosted language models to support organizational knowledge management and internal documentation retrieval.

The current version introduces a more advanced retrieval architecture and expanded document management capabilities beyond what is available in this repository.

## Status

This repository is maintained for historical reference purposes only.

No new features or significant updates are planned for this version.

For the latest development, features, and documentation, please refer to the current SynAccel AI repository.
