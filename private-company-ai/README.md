This project explores secure retrieval-augmented generation (RAG)
systems for enterprise knowledge bases.

Current Features:
- Local LLM via Ollama
- PDF ingestion
- Question answering

Planned Features:
- Multi-document support
- Citations
- Role-based access controls
- Prompt injection testing
- AI security assessment



------

## Current Status

This is an early prototype.

The current version:
- Loads a PDF
- Extracts text
- Uses a local LLM through Ollama
- Answers questions about the document

Future versions will focus on:
- Multi-document retrieval
- Citations
- Access controls
- AI security testing
